# Feature 5.8: Export de données pour les centres de formation

## Vue d'ensemble

Implémentation de la fonctionnalité d'export des données au format Excel pour les centres de formation, accessible depuis la page Paramètres.

## Fonctionnalité

### Format d'export: Excel (.xlsx)

L'export génère un fichier Excel multi-feuilles contenant toutes les données du centre:

#### 📋 **Feuille 1: Informations Centre**
- Nom de l'établissement
- SIRET
- Coordonnées (email, téléphone, adresse)
- Personne référente
- Statut certificateur
- Certification Qualiopi
- Plan d'abonnement
- Dates de création/mise à jour

#### 📨 **Feuille 2: Demandes Envoyées**
Toutes les demandes envoyées aux jurys avec:
- ID, Jury, Email
- Certification, Date de session
- Horaires (début/fin)
- Modalité (Présentiel/Visio/Hybride)
- Lieu, Nombre de candidats
- Statut (En attente/Acceptée/Refusée/Terminée/Annulée)
- Dates de création et mise à jour

#### ✅ **Feuille 3: Sessions Réalisées**
Filtre uniquement les sessions avec statut "completed":
- Mêmes informations que les demandes
- Uniquement les sessions terminées

#### ⭐ **Feuille 4: Évaluations Données**
Évaluations données par le centre aux jurys:
- Jury évalué
- Certification et date de session
- Notes (globale, ponctualité, professionnalisme, pédagogie)
- Commentaire
- Date d'évaluation

#### ⭐ **Feuille 5: Évaluations Reçues**
Évaluations reçues des jurys:
- Jury évaluateur
- Certification et date de session
- Notes (globale, communication, organisation, conditions)
- Commentaire
- Date d'évaluation

#### 🎓 **Feuille 6: Certifications FC** (si certificateur)
Certifications France Compétence liées:
- ID Certification, Titre, Code
- Niveau, Domaine
- Statut, Dates de validité
- Dernière mise à jour

#### 📊 **Feuille 7: Statistiques**
Statistiques agrégées:
- Total de demandes envoyées
- Répartition par statut (en attente, acceptées, refusées, terminées, annulées)
- Taux d'acceptation
- Taux de complétion
- Nombre d'évaluations données/reçues
- Date d'export

## Implémentation technique

### Fichiers créés/modifiés

1. **API Route**: `/app/api/center/export-data/route.ts`
   - Endpoint GET pour générer l'export Excel
   - Authentification requise (user_type = 'centre')
   - Récupération de toutes les données du centre
   - Génération du fichier Excel avec XLSX
   - Nom de fichier: `SimplyJury_Export_{NomCentre}_{Date}.xlsx`

2. **Component**: `/components/dashboard/center-settings.tsx`
   - Ajout de la fonction `handleExportData()`
   - État `isExporting` pour le loading
   - Bouton avec animation pendant l'export
   - Téléchargement automatique du fichier

### Dépendances requises

**⚠️ IMPORTANT: Package à installer**

```bash
pnpm add xlsx
pnpm add -D @types/node
```

Le package `xlsx` (SheetJS) est nécessaire pour:
- Créer des fichiers Excel (.xlsx)
- Gérer plusieurs feuilles (sheets)
- Formater les colonnes
- Générer le buffer pour le téléchargement

### Sécurité

- ✅ Authentification requise
- ✅ Vérification du type d'utilisateur (centre uniquement)
- ✅ Accès uniquement aux données du centre connecté
- ✅ Pas d'exposition de données sensibles (mots de passe, tokens)
- ✅ Utilisation de Supabase service role pour les requêtes

### Fonctionnalités

- ✅ Export multi-feuilles organisé par type de données
- ✅ Traduction des statuts et modalités en français
- ✅ Formatage des dates au format français (DD/MM/YYYY)
- ✅ Colonnes auto-dimensionnées pour lisibilité
- ✅ Nom de fichier personnalisé avec nom du centre et date
- ✅ Téléchargement automatique côté client
- ✅ État de chargement pendant l'export

### UX

- Bouton "Exporter" dans la section "Données et confidentialité"
- Animation de l'icône pendant l'export
- Texte "Export en cours..." pendant le traitement
- Bouton désactivé pendant l'export
- Message d'erreur en cas de problème

## Format des données

### Traductions automatiques

- **Statuts**: pending → En attente, accepted → Acceptée, etc.
- **Modalités**: presentiel → Présentiel, visio → Visioconférence, hybride → Hybride
- **Dates**: Format français (DD/MM/YYYY HH:MM)

### Gestion des valeurs nulles

- Valeurs manquantes affichées comme "N/A" ou "Non renseigné"
- Tableaux vides gérés gracieusement
- Feuille "Certifications FC" uniquement si certificateur

## Utilisation

1. Aller dans **Paramètres** → **Données et confidentialité**
2. Cliquer sur le bouton **"Exporter"**
3. Le fichier Excel se télécharge automatiquement
4. Ouvrir avec Excel, LibreOffice, Google Sheets, etc.

## Avantages de l'export Excel

✅ **Format universel** - Compatible avec tous les outils bureautiques
✅ **Multi-feuilles** - Organisation claire des données par catégorie
✅ **Manipulation facile** - Filtres, tris, tableaux croisés dynamiques
✅ **Partage simple** - Facile à envoyer par email ou partager
✅ **Archivage** - Format standard pour l'archivage de données
✅ **Conformité RGPD** - Permet l'exercice du droit à la portabilité
