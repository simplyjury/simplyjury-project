# F2.16 Enhancement - Improved Layout and Approval Status Filtering

## Overview
This enhancement improves the certifications page (`/dashboard/center/certifications`) with better filtering and a more readable collapsed/expandable row layout.

**Implementation Date**: 2025-10-10

## Problems Solved

### 1. Filtering Issue
- **Problem**: No way to filter certifications by approval status (approved/pending/rejected)
- **Constraint**: "Status" filter already exists for RNCP training status (active/inactive/expired)
- **Solution**: Implemented visual tabs for approval status filtering

### 2. Readability Issue
- **Problem**: Too much text in each row, hard to distinguish between certifications
- **Solution**: Implemented collapsed/expandable rows with minimal visible information by default

## What Was Implemented

### 1. Approval Status Tabs

**Location**: `/app/dashboard/center/certifications/page.tsx`

#### Visual Design
Four color-coded tabs with counts:
- **Toutes** (Blue/Primary) - All certifications
- **Validées** (Green) - Approved certifications with ✓ icon
- **En attente** (Yellow) - Pending certifications with ⏰ icon
- **Rejetées** (Red) - Rejected certifications with ✗ icon

#### Features
- ✅ Real-time count badges on each tab
- ✅ Active tab highlighted with colored background
- ✅ Responsive design (wraps on mobile)
- ✅ Smooth transitions
- ✅ Filters work in combination with existing search and RNCP status filters

#### State Management
```typescript
const [approvalStatusTab, setApprovalStatusTab] = useState<'all' | 'approved' | 'pending' | 'rejected'>('all');

// Calculate counts for tabs
const approvalStatusCounts = {
  all: certifications.length,
  approved: certifications.filter(c => (c.approval_status || 'approved') === 'approved').length,
  pending: certifications.filter(c => c.approval_status === 'pending').length,
  rejected: certifications.filter(c => c.approval_status === 'rejected').length,
};
```

#### Filtering Logic
```typescript
// Approval status tab filter
if (approvalStatusTab !== 'all') {
  const certApprovalStatus = cert.approval_status || 'approved';
  if (approvalStatusTab !== certApprovalStatus) return false;
}
```

### 2. Collapsed/Expandable Row Layout

**Location**: `/components/certifications/certification-card.tsx`

#### Collapsed State (Default)
Shows only essential information in a single compact row:

```
▶ [Icon] Certification Title | RNCP12345 | [Badge] | 45 candidats | 92% | [Active]
```

**Visible Elements**:
- Expand/collapse chevron icon (▶/▼)
- Domain icon (emoji)
- Certification title (truncated if too long)
- RNCP code badge
- Approval status badge (if pending/rejected)
- Quick stats (candidates count, success rate) - hidden on mobile
- RNCP status badge (Active/Inactive/Expired)

**Benefits**:
- Clear separation between rows
- Easy to scan multiple certifications
- Minimal cognitive load
- Better use of horizontal space

#### Expanded State (On Click)
Shows full details in a light gray background:

**Sections**:
1. **Approval Status Banner** (if pending/rejected)
   - Yellow banner for pending with explanation
   - Red banner for rejected with admin comment

2. **Detailed Information Grid**
   - Left column: Calendar info, candidates, success rate
   - Right column: Tags (level, domain, + limited tags)

3. **Competency Blocks**
   - All blocks displayed in white chips
   - Collapsible section

4. **Action Buttons**
   - Full action buttons at bottom
   - Separated by border

#### Interaction Design
- **Click anywhere on row** to expand/collapse
- **Click on buttons** doesn't trigger expand (stopPropagation)
- **Hover effect** on collapsed row
- **Smooth transitions** between states
- **Each row maintains its own state** (independent expand/collapse)

### 3. Visual Improvements

#### Better Hierarchy

#### Spacing and Borders
- Clean border between rows
- No border on last item
- Light gray background on expanded content
- Proper padding throughout

#### Mobile Responsiveness
- Quick stats hidden on mobile in collapsed view
- Grid becomes single column on mobile when expanded
- Tabs wrap on mobile
- All touch targets properly sized

## Technical Implementation

### State Management

**Page Level** (`page.tsx`):
```typescript
const [approvalStatusTab, setApprovalStatusTab] = useState<'all' | 'approved' | 'pending' | 'rejected'>('all');
```

**Component Level** (`certification-card.tsx`):
```typescript
const [isExpanded, setIsExpanded] = useState(false);
```

### Helper Functions

**Get Approval Status Badge**:
```typescript
const getApprovalStatusBadge = () => {
  if (certification.approval_status === 'pending') {
    return <Badge className="bg-yellow-100...">En attente</Badge>;
  }
  if (certification.approval_status === 'rejected') {
    return <Badge className="bg-red-100...">Rejetée</Badge>;
  }
  return null; // No badge for approved
};
```

### Event Handling

**Expand/Collapse**:
```typescript
<div onClick={() => setIsExpanded(!isExpanded)}>
  {/* Row content */}
</div>
```

**Button Clicks** (prevent expand):
```typescript
<Button onClick={(e) => {
  e.stopPropagation();
  onFindJuries(certification.id);
}}>
```
