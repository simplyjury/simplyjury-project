# F2.16 Enhancement - Email Notifications for Certification Decisions

## Overview
This enhancement adds automatic email notifications to training centers when an admin approves or rejects their SIRET mismatch certification requests from the validation page.

**Implementation Date**: 2025-10-10

**Features**:

### 3. API Endpoint Enhancement

**File**: `/app/api/admin/certifications/[id]/route.ts`

**Changes Made**:
1. ✅ Added import for `trainingCenters` schema
2. ✅ Added import for `sendCertificationDecisionEmail` action
3. ✅ Fetch certification WITH training center details before update
4. ✅ Extract center name and email (with fallback to user email)
5. ✅ Call email sending function asynchronously after update
6. ✅ Non-blocking email sending (errors logged but don't fail request)

**Flow**:
```
Admin clicks Approve/Reject
  ↓
API fetches certification + training center data
  ↓
API updates certification approval_status
  ↓
API triggers email sending (async, non-blocking)
  ↓
API returns success response
  ↓
Frontend removes item from validation list
  ↓
Training center receives email notification
```

## How It Works

### Admin Workflow
1. Admin navigates to `/dashboard/admin/validation-profils`
2. Sees pending certification with SIRET mismatch warning
3. Clicks approve ✅ or reject ❌ button
4. Optionally adds a comment
5. Confirms action
6. **NEW**: Email automatically sent to training center
7. Certification removed from validation queue
8. Badge count updated

### Training Center Experience
1. Receives immediate email notification
2. Email contains:
   - Clear decision (approved/rejected)
   - Certification details
   - Admin's comment (if provided)
   - Next steps
   - Relevant CTA button
3. Can take appropriate action based on decision

## Technical Details

### Email Sending
- **Provider**: Resend API
- **From Address**: `SimplyJury <notifications@simplyjury.com>`
- **Recipient**: Training center email (or user email as fallback)
- **Execution**: Asynchronous, non-blocking
- **Error Handling**: Logged but doesn't block API response

### Database Queries
```sql
-- Fetch certification with center details
SELECT 
  fcc.*,
  tc.name as centerName,
  tc.email as centerEmail,
  u.email as userEmail
FROM france_competence_certifications fcc
LEFT JOIN training_centers tc ON fcc.training_center_id = tc.id
LEFT JOIN users u ON tc.user_id = u.id
WHERE fcc.id = {certificationId}
```
