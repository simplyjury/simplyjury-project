# F1.8 - Compétences par Code ROME

## 📋 Vue d'ensemble

Implémentation d'un système complet de gestion des codes ROME (Répertoire Opérationnel des Métiers et des Emplois) pour SimplyJury, incluant le téléchargement automatique depuis la source officielle France Travail, la transformation en JSON, et l'intégration dans l'interface de recherche.

---

## 🎯 Objectif

Permettre aux jurys de sélectionner leurs domaines d'expertise via des codes ROME officiels, avec :
- Recherche autocomplete avec fuzzy matching
- Mise à jour automatisée des codes depuis France Travail Open Data
- Interface admin pour gérer les mises à jour
- 1,584 codes ROME disponibles couvrant tous les métiers en France

---

## 🛠️ Implémentation Technique

### **1. Script de Téléchargement**

**Fichier:** `/scripts/fetch-rome-codes-from-open-data.js`

**Fonctionnalités:**
- Télécharge le fichier Excel depuis data.gouv.fr
- Gère les redirections HTTP
- Parse le fichier Excel avec la bibliothèque `xlsx`
- Extrait les codes ROME depuis la feuille "Arbo Principale"

**Structure du fichier Excel:**
```
Colonne A: Lettre de catégorie (ex: "A", "M", "D")
Colonne B: Premiers 2 chiffres (ex: "11", "18", "12")
Colonne C: Derniers 2 chiffres (ex: "01", "05", "02")
Colonne D: Libellé du métier

Exemple:
A + 11 + 01 = A1101 (Conducteur d'engins agricoles)
M + 18 + 05 = M1805 (Développeur informatique)
D + 12 + 02 = D1202 (Coiffeur)
```

**Code d'extraction:**
```javascript
// Concaténation des colonnes pour former le code ROME
const colA = row[0];  // Lettre
const colB = row[1];  // Premiers 2 chiffres
const colC = row[2];  // Derniers 2 chiffres  
const label = row[3]; // Description

const code = `${colA}${colB}${colC}`.trim(); // Ex: "M1805"

// Validation du format (1 lettre + 4 chiffres)
const romePattern = /^[A-Z]\d{4}$/;
if (romePattern.test(code)) {
  romeCodes.push({
    code: code,
    label: label.toString().trim(),
    categoryCode: code.substring(0, 3) // Ex: "M18"
  });
}
```

**Exécution:**
```bash
node scripts/fetch-rome-codes-from-open-data.js
```

### **4. Recherche Fuzzy (Floue)**

**Implémentation:** Normalisation du texte + correspondance par mots-clés

**Fonctionnalités:**
1. **Suppression des accents**
   - "développeur" → "developpeur"
   - "financière" → "financiere"

2. **Normalisation du genre**
   - "financière" → "financier"
   - "développeuse" → "développeur"
   - "directrice" → "directeur"

3. **Recherche par mots-clés**
   - "ingénierie financière" → ["ingénierie", "financière"]
   - Trouve les résultats contenant N'IMPORTE QUEL mot-clé

**Code:**
```typescript
function normalizeText(text: string): string {
  let normalized = text.toLowerCase();
  
  // Gestion des variations de genre AVANT suppression des accents
  normalized = normalized
    .replace(/ière\b/g, 'ier')        // financière → financier
    .replace(/euse\b/g, 'eur')        // développeuse → développeur  
    .replace(/trice\b/g, 'teur');     // directrice → directeur
  
  // Suppression des accents
  normalized = normalized
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '');
  
  return normalized.trim();
}

function fuzzyMatch(searchText: string, targetText: string): boolean {
  const normalizedSearch = normalizeText(searchText);
  const normalizedTarget = normalizeText(targetText);
  
  // Découpage en mots-clés (ignore les mots < 3 caractères)
  const keywords = normalizedSearch
    .split(/\s+/)
    .filter(word => word.length > 2);
  
  // Correspondance si N'IMPORTE QUEL mot-clé apparaît
  return keywords.some(keyword => normalizedTarget.includes(keyword));
}
```

**Exemples de recherche:**

| Recherche | Trouve | Raison |
|-----------|--------|--------|
| "développeur" | M1805 - Développeur informatique | ✅ Correspondance exacte |
| "développeuse" | M1805 - Développeur informatique | ✅ Genre normalisé |
| "developpeur" | M1805 - Développeur informatique | ✅ Accent supprimé |
| "ingénierie financière" | M1201 - Analyste financier | ✅ Mot-clé "financier" |
| "coiffeur" | D1202 - Coiffeur / Coiffeuse | ✅ Correspondance exacte |

### **5. Cache en Mémoire**

**Implémentation:**
```typescript
let romeCodesCache: any = null;
let lastLoadTime = 0;
const CACHE_DURATION = 60 * 60 * 1000; // 1 heure

function loadRomeCodes() {
  const now = Date.now();
  
  // Retourne le cache si valide
  if (romeCodesCache && (now - lastLoadTime) < CACHE_DURATION) {
    return romeCodesCache;
  }
  
  // Recharge depuis le fichier
  const jsonPath = path.join(process.cwd(), 'lib/data/rome-codes.json');
  const jsonData = fs.readFileSync(jsonPath, 'utf8');
  romeCodesCache = JSON.parse(jsonData);
  lastLoadTime = now;
  
  return romeCodesCache;
}
```

**Avantages:**
- ✅ Lecture du fichier une seule fois par heure
- ✅ Réponses instantanées (< 10ms)
- ✅ Pas de charge sur le disque
- ✅ Mise à jour automatique après 1h

## 🔒 Sécurité et Validation

### **Validation du Format**

**Pattern:** `^[A-Z]\d{4}$`

**Exemples valides:**
- ✅ `M1805`
- ✅ `D1202`
- ✅ `A1101`

**Exemples invalides:**
- ❌ `m1805` (minuscule)
- ❌ `M18` (trop court)
- ❌ `M18055` (trop long)
- ❌ `1805` (pas de lettre)

### **Déduplication**

```javascript
const seenCodes = new Set();

if (!seenCodes.has(code)) {
  seenCodes.add(code);
  romeCodes.push({...});
}
```

### **Tri Alphabétique**

```javascript
romeCodes.sort((a, b) => a.code.localeCompare(b.code));
```

### **Composant de Recherche**

**Utilisation dans le profil jury:**

```typescript
// Recherche avec debounce (300ms)
const handleSearch = debounce(async (query: string) => {
  const response = await fetch(`/api/rome/search?q=${query}&limit=10`);
  const data = await response.json();
  setSuggestions(data.results);
}, 300);

// Sélection d'un code
const handleSelect = (code: RomeCode) => {
  if (selectedCodes.length < 5) {
    setSelectedCodes([...selectedCodes, code]);
  }
};
```

```tsx
<div className="space-y-2">

    type="text"

  {/* Suggestions */}
  {suggestions.map(code => (
```

## 🐛 Dépannage

### **Problème: Aucun code trouvé**

**Solution:**
```bash
# Vérifier si le fichier existe
ls lib/data/rome-codes.json

# Si absent, exécuter le script
node scripts/fetch-rome-codes-from-open-data.js
```

### **Problème: Timeout lors du téléchargement**

**Cause:** data.gouv.fr est lent ou indisponible

**Solution:**
- Réessayer plus tard
- Vérifier la connexion internet
- Augmenter le timeout dans le script (actuellement 60s)

### **Problème: Format Excel changé**

**Symptôme:** 0 codes extraits

**Solution:**
1. Exécuter: `node scripts/inspect-rome-excel.js`
2. Vérifier la structure du fichier
3. Ajuster les indices de colonnes dans le script
